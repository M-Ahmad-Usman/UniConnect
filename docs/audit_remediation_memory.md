# Audit Remediation Memory

Temporary working memory for the production-readiness audit implementation.

## Decisions
- Programs belong in Academics as the primary UI location.
- Admins own program catalog creation/editing.
- HODs manage courses, curriculum, classes, and societies inside their own department.
- Program Directors manage curriculum only for their directed programs.
- Query errors should render inline first; mutation/realtime errors may use toasts.
- Test names should use domain workflows, not historical module numbers.
- Initial deployment target is a single backend instance; Redis/shared Socket.IO/rate-limit infrastructure is a pre-scale requirement.
- Admin MFA is deferred to a security audit item, not implemented in this pass.
- New-post notification fanout should use set-based SQL now; no queue is added.
